# F1-WP01 — Identity bootstrap

Status: **Done**

## Goal

Menyediakan tenant, admin user global, membership tenant, UUIDv7, password scrypt, migration additive, dan bootstrap super admin tanpa password hardcoded.

## File yang berubah

`packages/db/prisma/*`, `packages/db/src/*`, secret initializer, Compose API secret/environment, dan decision record F1.

## Non-goal

OIDC/SSO, tenant switch dalam session aktif, recovery UI, dan user-management UI.

## Migration dan security impact

Tiga migration membuat pgvector baseline, identity/session/audit, serta operational state. Password hanya dibaca dari file secret dan disimpan sebagai scrypt envelope; bootstrap idempotent tidak merotasi password user existing.

## Acceptance, test, evidence

- [x] Prisma `7.9.1` validate/generate/build lulus.
- [x] Tiga migration berhasil diterapkan pada database kosong yang sebelumnya belum memiliki schema aplikasi.
- [x] Bootstrap membuat tenant, super admin, membership, safety, WhatsApp state, dan audit tanpa mencetak password.
- [x] Unit test UUIDv7 dan scrypt lulus.
- [x] `test:db` memverifikasi 7 tabel, pgvector `0.8.6`, dan minimal satu scrypt user.

## Rollback

Gunakan restore/recreate database pilot sebelum data riil. Tidak ada destructive down migration otomatis untuk identity/audit.
