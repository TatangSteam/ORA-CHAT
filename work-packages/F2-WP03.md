# F2-WP03 — Transactional compose dan idempotency

Status: **Done**

## Goal

Membuat manual outbound sebagai satu transaction berisi `Message`, initial `MessageEvent`, `OutboxMessage`, `IdempotencyKey`, dan audit.

## Security dan data impact

Mutation memerlukan `messages.send`, CSRF, `Idempotency-Key`, WhatsApp connected, dan safety clear. Recipient opted-out/playground ditolak. Key kedaluwarsa setelah tujuh hari dan dipurge worker.

## Acceptance dan evidence

- [x] Request identik dengan key sama mengembalikan resource sama.
- [x] Payload berbeda dengan key sama menghasilkan `409 IDEMPOTENCY_CONFLICT`.
- [x] Kegagalan transaction tidak meninggalkan subset row.
- [x] Source manual, rule, dan AI menggunakan repository/outbox path yang sama.

## Non-goal dan rollback

Template terjadwal Fase 6 bukan scope. Rollback menghentikan producer tanpa menghapus durable outbox.
