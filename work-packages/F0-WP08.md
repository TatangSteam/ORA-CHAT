# F0-WP08 — App Shell

Status: **Done**

## Goal

Memindahkan token, navigasi, layout, dan interaction pattern operational shell lama ke Next.js App Router tanpa membuat ulang desain atau fake functionality.

## Scope dan security impact

Shell mencakup login, overview, session WhatsApp, dan safety pada desktop/mobile. Next tetap presentation layer dan same-origin proxy; browser tidak menerima token session atau akses Prisma. Route yang belum tersedia ditampilkan inactive.

## Acceptance dan evidence

- [x] Sembilan design token Gate A digunakan secara exact.
- [x] Struktur sidebar/topbar/card/status dan navigasi mobile tersedia dalam bahasa Indonesia.
- [x] Login kembali memakai card terpusat sesuai struktur baseline; tenant bootstrap tetap dikirim tersembunyi dan tidak mengubah auth contract.
- [x] Playwright membandingkan delapan screenshot viewport desktop/mobile dengan baseline Gate A tanpa mengganti baseline.
- [x] Axe WCAG 2.2 AA, keyboard focus, reduced motion, dan horizontal overflow diperiksa pada empat route di dua viewport.
- [x] Production build Next lulus.

Command evidence: `corepack pnpm test:visual`, `corepack pnpm test:a11y`, `corepack pnpm build`.

## Rollback

Rollback route atau stylesheet tidak menyentuh database, auth cookie, atau durable operational state.
