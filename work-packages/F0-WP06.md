# F0-WP06 — MinIO foundation

Status: **Done untuk local/self-hosted foundation; production release tetap blocked oleh security exception**

## Goal

Menyediakan image internal `raho/minio-full:2025-04-22-r1` dari release/digest yang disetujui, runtime non-root, bootstrap idempoten, bucket private, lifecycle/versioning, dan credential least-privilege tanpa memberikan root kepada API/worker.

## Kebijakan storage

- `raho-quarantine`: expiry 1 hari.
- `raho-knowledge`: versioning aktif; non-current version 30 hari sebagai recovery window awal.
- `raho-exports`: expiry 1 hari dan quota awal 1 GiB.
- API dapat menulis quarantine serta membaca knowledge/export, tetapi tidak dapat menghapus quarantine.
- Worker dapat memproses/menghapus quarantine dan mengelola object knowledge/export.
- Operator bernama berada pada group `raho-operators`; root tetap hanya bootstrap/break-glass.

## Acceptance dan evidence

- [x] MinIO release/digest dan `mc` exact-pin; internal wrapper berlabel provenance.
- [x] MinIO berjalan UID/GID 1000, read-only root filesystem, no-new-privileges, tanpa capability.
- [x] Bootstrap dua kali selesai exit `0` dan tidak mencetak credential.
- [x] Tiga bucket private, versioning/lifecycle tervalidasi.
- [x] Upload/read/delete least-privilege dan dua object version tervalidasi.
- [x] IAM policy, group, service account, quota, dan event configuration endpoint tervalidasi.
- [x] API/worker menerima hanya service credential masing-masing dan readiness memakai authenticated bucket probe.

Command evidence: `corepack pnpm test:minio`.

## Release caveat

Legacy full-console ini hanya diizinkan local saat ini. Pilot/production tetap wajib memiliki vulnerability register, container scan tanpa High/Critical unmitigated, AGPL corresponding source/SBOM, backup/restore drill, dan security exception tertulis.
