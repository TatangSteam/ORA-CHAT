# F1-WP02 — Session auth

Status: **Done**

## Goal

Login, logout, expiry, idle timeout, rotation, revocation, password invalidation, opaque cookie, CSRF, rate limit, dan generic failure response.

## File yang berubah

`apps/api/src/app.ts`, `security.ts`, `rate-limit.ts`, `repository.ts`, auth contracts, dan auth integration test.

## Non-goal

Redis-backed distributed limiter dan account recovery.

## Migration dan security impact

Session menyimpan hash token/CSRF/IP/user-agent; plaintext token hanya berada pada cookie response. Absolute TTL 8 jam, idle 30 menit, lima concurrent session, dan password change merevoke semua session user.

## Acceptance, test, evidence

- [x] Login CSRF dan authenticated mutation CSRF ditolak bila salah/hilang.
- [x] Cookie production memiliki `HttpOnly`, `Secure`, `SameSite=Lax`; token tidak muncul pada JSON.
- [x] Generic invalid credentials, exponential delay, dan 5-attempt rate limit diuji.
- [x] Logout merevoke record; smoke test memastikan cookie lama mendapat `401`.
- [x] Worker menjalankan retention session enam-jam sekali dan saat startup; revoked/expired session baru dihapus setelah cutoff 30 hari.
- [x] Runtime fixture membuktikan record 31 hari terhapus dan record 29 hari tetap dipertahankan.
- [x] Security integration membuktikan session fixation gagal, idle expiry membersihkan cookie, dan perubahan password merevoke seluruh session lama.

## Rollback

Disable route pada reverse proxy dan revoke seluruh session aktif; identity/audit tetap dipertahankan.
