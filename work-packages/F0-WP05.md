# F0-WP05 — Queue foundation

Status: **Done**

## Goal

Menyediakan BullMQ `6.0.7` dan ioredis `5.11.1` dengan connection factory terpisah, payload tervalidasi, job ID deterministik, worker readiness/graceful shutdown, serta safety gate sebelum delivery.

## Safety dan durability

Payload antrean hanya membawa identifier. `outbound.delivery` membaca `SafetyControlState` terbaru dari PostgreSQL; delivery tidak dipanggil saat pause atau kill switch aktif. Redis memakai AOF dan bukan source of truth domain.

## Acceptance dan evidence

- [x] Exact pin BullMQ/ioredis dan queue namespace per environment.
- [x] Job schema strict menolak body pesan atau field tambahan.
- [x] Duplicate logical probe memakai job ID yang sama.
- [x] Worker readiness menunggu Redis, PostgreSQL, dan authenticated MinIO probe.
- [x] Unit test membuktikan pause dan kill switch mencegah delivery.
- [x] Runtime probe diproses sebelum dan setelah restart Redis/worker.
- [x] Bootstrap PostgreSQL sesudah restart tetap idempoten (`created:false`).

Command evidence: `corepack pnpm test:unit`, `corepack pnpm test:queue`.
