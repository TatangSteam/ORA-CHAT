# F2-WP06 — Ordered chatbot rule versioning

Status: **Done**

## Goal

Menyediakan draft version, ordered deterministic rules, isolated playground, optimistic revision, dan atomic publish.

## Data dan security impact

Satu published version per tenant dijaga partial unique index. Publish memerlukan `chatbot.manage`, CSRF, alasan, revision, transaction, dan audit.

## Acceptance dan evidence

- [x] Sequence unik dan trigger exact/contains/starts-with tervalidasi.
- [x] Stale revision menghasilkan conflict.
- [x] Publish mengganti versi aktif secara atomic.
- [x] Playground tidak membuat contact, recipient, message, atau outbox.
- [x] Inbound published rule/fallback memakai outbox durable yang sama.

## Rollback

Versi lama tetap immutable secara aplikasi dan dapat dipakai sebagai sumber draft baru; rollback tidak mengedit versi published.
