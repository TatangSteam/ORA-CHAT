# F2-WP07 — Messaging operational UI

Status: **Done**

## Goal

Menyediakan Inbox/timeline, Kontak, Tulis pesan, Riwayat outbox, Handoff, dan Chatbot rules pada App Shell Indonesia tanpa business backend di Next.js.

## Security dan accessibility

UI memakai same-origin Express API, opaque cookie, CSRF, dan permission-aware navigation/action. Backend RBAC tetap enforcement utama.

## Acceptance dan evidence

- [x] Enam route Fase 2 memiliki loading, empty, error, dan action state yang nyata.
- [x] Desktop sidebar dan mobile bottom navigation tetap sesuai design token.
- [x] Dua puluh screenshot seluruh shell desktop/mobile memakai baseline aktual dan batas diff 2%.
- [x] Axe WCAG 2.2 AA, keyboard login, dan horizontal-overflow check lulus (6 suite).

## Rollback

Route dapat disembunyikan tanpa mengubah durable message/outbox; API tetap dapat dipakai untuk rekonsiliasi.
