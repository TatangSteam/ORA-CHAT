# F2-WP04 — Durable outbox delivery

Status: **Done**

## Goal

Menjadikan PostgreSQL source of truth delivery dengan BullMQ sebagai wake-up signal, lease, bounded retry, dan rekonsiliasi eksplisit.

## Scope

Dispatcher due-outbox, deterministic job ID, lease ownership/expiry, safety-gated worker, protected WhatsApp send boundary, cancel/retry/reconcile API, dan timeline event.

## Acceptance dan evidence

- [x] Redis restart direkonsiliasi dari PostgreSQL.
- [x] Crash sebelum provider acceptance menjadi `retryable` dan dapat dikirim ulang.
- [x] Crash setelah state `sending` menjadi `unknown` dan tidak auto-resend.
- [x] Provider acceptance mock menyimpan provider message ID serta status `sent`.
- [x] Pause/kill switch dibaca dari PostgreSQL sebelum setiap delivery.

## Non-goal dan rollback

Validasi nomor bisnis pada provider nyata adalah pilot gate terpisah. Worker dapat dihentikan tanpa kehilangan row; unknown hanya diputuskan melalui audit reconciliation.
