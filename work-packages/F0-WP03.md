# F0-WP03 — Compose infrastructure

Status: **Done**
Fase: **0 — Foundation**

## Goal

Menyediakan satu proyek Docker Compose lokal yang menjalankan web, API, worker, WhatsApp runtime, PostgreSQL/pgvector, Redis, MinIO, dan one-shot MinIO connectivity bootstrap sebagai service terpisah dengan image exact, network terisolasi, named volume, file-based secret, dan health check nyata.

## Perilaku saat ini

- Belum ada Compose V2 atau Dockerfile aplikasi.
- Hanya API yang memiliki endpoint live.
- Worker dan WhatsApp hanya mengekspor nama service lalu process selesai.
- Belum ada boundary secret, internal network, atau named volume V2.

## Perilaku yang diinginkan

- Satu `compose.yaml` mendefinisikan delapan service terpisah: `web`, `api`, `worker`, `whatsapp`, `postgres`, `redis`, `minio`, dan `minio-init`.
- PostgreSQL, Redis, dan MinIO memakai image exact beserta digest multi-platform yang telah diverifikasi.
- Satu image aplikasi Node exact dapat dipakai ulang oleh empat service aplikasi dengan command berbeda.
- Data service hanya berada pada network internal; port operator/aplikasi yang diperlukan development di-bind ke loopback.
- Data PostgreSQL, Redis, dan MinIO disimpan pada named volume.
- Password/credential dibuat acak ke `.secrets/` dan dipasang sebagai Compose secret; tidak ada nilai secret pada source atau environment example.
- Setiap service long-running memiliki health check yang memeriksa process/protocol aktual. `minio-init` wajib selesai sukses setelah memverifikasi credential dan readiness server.

## Non-goal

- Prisma schema, migration, atau pgvector index; dikerjakan pada F0-WP04.
- BullMQ connection/worker dan recovery test; dikerjakan pada F0-WP05.
- Bucket, policy, versioning, lifecycle, operator/service-account IAM, atau hardened MinIO image; dikerjakan pada F0-WP06.
- Shared API contract lengkap dan dependency readiness; dikerjakan pada F0-WP07.
- Port UI lama/App Shell; dikerjakan pada F0-WP08.
- Production deployment atau production approval legacy MinIO.

## Data/migration impact

Tidak ada migration. Named volume baru hanya menyediakan durable storage kosong untuk work package berikutnya. Menghapus volume adalah tindakan destructive dan tidak menjadi bagian rollback otomatis.

## Security/privacy impact

- Secret tidak disimpan di Git, Compose environment, command argument, atau image.
- Port host hanya bind ke `127.0.0.1`; PostgreSQL dan Redis tidak dipublish.
- Data network bersifat internal.
- Application container berjalan sebagai non-root, read-only, tanpa Linux capability, dan `no-new-privileges`.
- Legacy MinIO image hanya untuk local development sampai F0-WP06 menyediakan image internal hardened dan security evidence.

## Rollback/recovery

Stop service dengan `docker compose down` tanpa `--volumes`. File konfigurasi dapat di-revert tanpa menyentuh named volume. Secret lokal tetap berada di `.secrets/` sampai pengguna menghapus atau merotasinya secara eksplisit.
