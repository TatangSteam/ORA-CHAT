# F1-WP07 — Safety state

Status: **Done**

## Goal

Pause/resume/reset safety dengan reason, permission, CSRF, optimistic revision, durability, dan audit.

## File yang berubah

Safety migration/repository/routes dan halaman safety.

## Non-goal

Fase 2 durable outbox dan worker delivery policy lengkap.

## Migration dan security impact

State tenant-scoped dan revisioned. Reset memerlukan Super Admin (`safety.reset`), typed confirmation, dan feature flag disabled-by-default.

## Acceptance, test, evidence

- [x] Pause/resume API dan UI memerlukan reason, permission, CSRF, serta expected revision.
- [x] State durable dan mutation diaudit atomic.
- [x] Reset high-risk berada di belakang feature flag.
- [x] Worker BullMQ membaca safety state PostgreSQL pada setiap `outbound.delivery`; pause atau kill switch menghasilkan `blocked` dan tidak memanggil delivery adapter.
- [x] Unit test membuktikan jalur pause, kill switch, dan allowed delivery; runtime queue/restart probe lulus.

## Rollback

Pertahankan state terakhir; rollback aplikasi tidak boleh menganggap `sendingPaused=false` secara default.
