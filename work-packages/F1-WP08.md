# F1-WP08 — Operational UI dan visual parity

Status: **Done**

## Goal

Port login, overview, WhatsApp session, dan safety ke Next App Router dengan shell lama, bahasa Indonesia, responsive layout, serta kontrol keyboard/focus.

## File yang berubah

`apps/web/src/app/*`, shared shell/session hook, same-origin API client, dan Next rewrite.

## Non-goal

Redesign visual dan halaman Fase 2/3.

## Migration dan security impact

Frontend tidak mengakses Prisma, tidak menyimpan session token, dan hanya memanggil same-origin Express API. Menu permission-aware bukan pengganti backend authorization.

## Acceptance, test, evidence

- [x] Route `/login`, `/overview`, `/session`, `/safety` production-build lulus.
- [x] Desktop sidebar, mobile bottom navigation, focus-visible, label, error summary, dan reduced-motion tersedia.
- [x] SSE dengan fallback polling tersedia pada overview.
- [x] Delapan screenshot login/overview/session/safety desktop/mobile dibandingkan langsung dengan baseline Gate A menggunakan ambang pixel yang terdokumentasi.
- [x] Axe WCAG 2.2 AA, keyboard focus, dan horizontal overflow lulus pada empat route di desktop/mobile (6 Playwright suite passed).

## Rollback

Rollback route Next tidak mengubah database; API dan session tetap dapat direvoke independen.
