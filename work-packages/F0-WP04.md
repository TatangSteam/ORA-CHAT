# F0-WP04 — Database baseline

Status: **Done**

## Goal

Menyediakan Prisma `7.9.1`, PostgreSQL `18.4`, pgvector `0.8.6`, generated client ESM, connection adapter PostgreSQL, dan migration additive yang dapat dijalankan dari database kosong.

## Scope dan non-goal

File yang berubah berada di `packages/db/prisma/*`, `packages/db/src/*`, Docker image, package/lockfile, dan database verification script. Queue schema, MinIO metadata, serta domain Fase 2/3 bukan scope.

## Migration/security impact

Migration pertama hanya `CREATE EXTENSION IF NOT EXISTS vector`. Migration berikutnya additive dan tidak memiliki destructive down migration. Connection string dirakit dari Compose secret; build tidak menyalin secret.

## Acceptance dan evidence

- [x] Prisma CLI/client/adapter exact `7.9.1` dan PostgreSQL driver exact-pin.
- [x] `prisma validate`, `prisma generate`, typecheck, dan production build lulus.
- [x] Tiga migration diterapkan sukses pada database volume yang belum memiliki schema aplikasi.
- [x] Runtime membuktikan PostgreSQL `18.4`, pgvector image/extension `0.8.6`, tiga migration selesai, dan tujuh tabel awal tersedia.
- [x] API readiness melakukan query database nyata.

## Rollback/recovery

Untuk local/pilot sebelum data riil, rollback memakai database recreate/restore terkontrol. Setelah data riil, gunakan forward migration; audit tidak boleh dihapus otomatis.
