# F2-WP01 — Contact normalization dan conversation

Status: **Done**

## Goal

Menyediakan contact Indonesia yang ternormalisasi, pencegahan duplikat per tenant, serta conversation list/detail dengan cursor pagination.

## Scope dan data impact

Shared Zod contract, repository tenant-scoped, API contact/conversation, serta migration additive `Contact` dan `Conversation` dengan unique/index tenant-leading.

## Security dan non-goal

Tenant selalu berasal dari session; path/query/body tidak dapat menggantinya. Import massal dan merge contact berada di luar Fase 2.

## Acceptance dan evidence

- [x] Format `08`, `8`, `+62`, dan `62` menjadi nomor `62...`/provider JID yang sama.
- [x] Unique `(tenantId, normalizedPhone)` mencegah duplikat dan create bersifat idempotent secara domain.
- [x] List contact/conversation memakai cursor/limit tervalidasi.
- [x] Cross-tenant contact ID menghasilkan `404` pada runtime smoke.

## Rollback

Schema additive dipertahankan; aplikasi lama dapat mengabaikan tabel baru.
