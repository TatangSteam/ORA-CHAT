# F0-WP02 — Quality baseline dan CI

Status: **Done**  
Fase: **0 — Foundation**

## Goal

Menetapkan quality gate lintas platform yang menjalankan formatter check, lint, strict typecheck, unit test, integration test nyata, dependency audit, transitive license scan, CycloneDX SBOM, exact version check, dan production build.

## Dependency

- Gate A passed.
- F0-WP01 berstatus Done.

## File/directory yang boleh berubah

- Root quality configuration dan package manifest.
- `.github/workflows/*`.
- `scripts/*` untuk quality automation.
- Test foundation di `apps/*`, `packages/*`, dan `tests/*`.
- Dokumentasi V2 dan `work-packages/*`.

## Perilaku sebelum implementasi

- Lint, typecheck, 3 test, dan build tersedia.
- Unit dan integration test belum dipisahkan.
- Belum ada formatter check, dependency/license policy, SBOM, version report, atau CI.

## Perilaku yang diinginkan

- Semua dependency tooling memakai versi exact dan tercatat di lockfile.
- Unit test tidak mengonsumsi integration test secara tidak sengaja.
- Integration suite mempunyai minimal satu test TCP nyata dan gagal bila kosong.
- License scan menolak lisensi unresolved, proprietary, atau commercial.
- Dependency audit gagal untuk advisory High/Critical.
- SBOM CycloneDX tervalidasi dan dapat diunduh dari CI.
- CI menggunakan Node target dan action yang dipin ke commit SHA.
- Tidak ada placeholder pass atau ignored registry error.

## Non-goal

- Docker Compose dan container scan; dimulai pada F0-WP03.
- Prisma/database integration; dimulai pada F0-WP04.
- Redis/BullMQ, MinIO, WhatsApp, auth, RBAC, atau fitur bisnis.
- Menyatakan Fase 0 atau Fase 1 selesai.

## Data/migration impact

Tidak ada perubahan data atau schema.

## Security/privacy impact

- Audit dependency memakai registry dan harus gagal bila registry tidak dapat memberi hasil valid.
- SBOM dan laporan lisensi hanya berisi metadata package, tidak boleh membaca atau memuat `.env`/secret.
- GitHub Actions memakai permission read-only dan third-party actions dipin dengan SHA.

## Acceptance criteria

- [x] Frozen install lulus.
- [x] Formatter check dan ESLint lulus tanpa warning.
- [x] Strict typecheck seluruh workspace lulus.
- [x] Unit dan integration suite terpisah serta keduanya memiliki test nyata.
- [x] License scan direct/transitive lulus.
- [x] Audit High/Critical lulus tanpa mengabaikan registry error.
- [x] CycloneDX SBOM berhasil dibuat dan tervalidasi.
- [x] Version report menunjukkan mismatch lokal secara jujur; CI mengunci Node `24.18.0` dan pnpm `11.20.0`.
- [x] Production build seluruh workspace lulus.
- [x] Workflow CI tidak memakai placeholder success.
