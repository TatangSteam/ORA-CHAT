# F2-WP02 — Incoming message ingestion

Status: **Done**

## Goal

Menerima event Baileys melalui boundary internal terautentikasi, menyimpan incoming message sekali, dan menjalankan routing rule deterministik.

## Scope dan data impact

Adapter `messages.upsert`, internal bearer boundary, `Message`, `MessageEvent`, provider identifiers, dan event trigger append-only.

## Security dan non-goal

Token internal dibaca dari Docker secret; payload/QR/credential tidak dicetak. Media ingestion dan historical backfill bukan scope paket ini.

## Acceptance dan evidence

- [x] Provider event/message ID unik per tenant.
- [x] Duplicate provider event mengembalikan hasil replay tanpa message kedua.
- [x] Message event tidak dapat di-update/delete oleh role aplikasi.
- [x] Published rule menghasilkan outbound baru melalui outbox; fallback tetap deterministik.

## Rollback

Hentikan inbound callback; durable row tetap dipertahankan untuk rekonsiliasi.
