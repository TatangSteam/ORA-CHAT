# F1-WP06 — WhatsApp session control

Status: **Done**

## Goal

Menyediakan state, reconnect/reset dengan reason/revision/audit, serta QR short-lived yang tidak dipersist.

## File yang berubah

Operational state migration, session repository/routes, dan halaman session.

## Non-goal

Multi-session WhatsApp dan Cloud API.

## Migration dan security impact

Database hanya menyimpan state dan secure-storage reference; QR/auth material tidak memiliki kolom persistence. Reset memerlukan `safety.reset`, confirmation phrase, CSRF, dan reason.

## Acceptance, test, evidence

- [x] State read, reconnect, reset, optimistic revision, permission, CSRF, dan audit tersedia.
- [x] QR endpoint role-gated dan tidak membuat/menyimpan QR palsu.
- [x] Adapter Baileys `6.7.22` menyimpan auth hanya pada named volume terenkripsi-at-rest boundary dan QR hanya pada memory store TTL 60 detik.
- [x] Internal QR endpoint memakai bearer secret, `Cache-Control: no-store`, dan tidak mengekspos QR lewat log/database/Redis/MinIO.
- [x] API mengubah QR mentah menjadi PNG untuk browser; unauthenticated request ditolak dan runtime smoke menerima PNG nyata saat state `qr_required`.
- [x] Unit test membuktikan expiry, tenant isolation, rotation invalidation, dan concurrent-view consistency.

## Rollback

Biarkan state durable; disable control routes. Jangan menghapus auth volume atau state tanpa recovery procedure.
