# F1-WP03 — RBAC dan tenant context

Status: **Done**

## Goal

Menegakkan permission backend dan tenant context yang berasal hanya dari session-bound membership.

## File yang berubah

RBAC contracts/test, composite session foreign key, API middleware, dan repository tenant-scoped.

## Non-goal

Production RLS dan tenant/membership management endpoints.

## Migration dan security impact

Composite FK memastikan membership, user, dan tenant session konsisten. Override memakai schema grant/deny dengan deny precedence.

## Acceptance, test, evidence

- [x] Seluruh permission minimum ada pada vocabulary dan role matrix.
- [x] Permission middleware melindungi overview, audit, session, QR, dan safety endpoints.
- [x] Seluruh 12 protected endpoint dipetakan tepat satu kali dan diuji terhadap empat role serta deny override precedence.
- [x] IDOR test membuktikan path Fase 1 tidak membawa tenant ID, query/filter/pagination tidak dapat mengganti tenant session, body tenant injection ditolak, QR provider menerima tenant session, dan replay SSE tidak lintas tenant.

## Rollback

Tidak boleh menonaktifkan middleware. Rollback aplikasi harus kembali ke release yang masih memiliki tenant enforcement setara.
