# F0-WP01 — Monorepo dan exact toolchain

Status: **Done**  
Fase: **0 — Foundation**

## Goal

Membuat monorepo TypeScript V2 yang dapat di-install, lint, typecheck, test, dan build secara deterministik tanpa mengubah source aplikasi lama.

## Input/source of truth

- `REQUIREMENTS.md`
- `ERD.md`
- `AI_DEVELOPMENT_FLOW.md`
- `gate-a/DECISION_REGISTER.md`

## Dependency

- Gate A berstatus passed.
- GA-010 sampai GA-015 telah disetujui.

## File/directory yang boleh berubah

- Root configuration dalam `whatsapp-chatbot-v2`.
- `apps/*`, `packages/*`, dan `work-packages/*`.
- Dokumentasi V2.
- Tidak mengubah tracked source pada `whatsapp-chatbot/*`.

## Perilaku sebelum implementasi

Folder V2 hanya berisi requirement, ERD, development flow, dan Gate A artifacts.

## Perilaku yang diinginkan

- Workspace pnpm dengan aplikasi `web`, `api`, `worker`, dan `whatsapp`.
- Shared packages `contracts`, `config`, `db`, `ui`, dan `testing`.
- Exact dependency versions dan lockfile.
- Strict TypeScript, ESLint, Vitest, dan build commands dari root.
- Next.js App Router minimal yang dapat dibuild.
- Express API minimal dengan live endpoint; belum memiliki business endpoint.

## Non-goal

- Prisma schema dan migration.
- Docker Compose V2.
- Redis/BullMQ integration.
- MinIO integration.
- WhatsApp connection.
- Provider AI.
- Port UI lengkap.

## Data/migration impact

Tidak ada. Work package ini tidak terhubung ke database.

## Security/privacy impact

- Tidak ada secret atau data pelanggan.
- Environment file hanya berupa example tanpa nilai credential.
- API menonaktifkan `x-powered-by`.

## Acceptance criteria

- [x] Semua workspace package terdeteksi pnpm.
- [x] Tidak ada floating dependency range.
- [x] `pnpm lint`, `pnpm typecheck`, `pnpm test`, dan `pnpm build` lulus.
- [x] Next.js memakai App Router.
- [x] API live endpoint mempunyai test.
- [x] Node dan pnpm target tercatat; perbedaan runtime lokal dilaporkan jujur.

## Deviasi tervalidasi

- Baseline menyebut `@eslint/js@10.8.0`, tetapi versi tersebut tidak tersedia di npm registry pada tanggal verifikasi. Package pendamping ini dikunci ke `10.0.1`, sedangkan engine `eslint` tetap `10.8.0` sesuai baseline.
- Host lokal menjalankan Node `24.16.0`, bukan target `24.18.0`; seluruh gate lulus dengan warning engine. CI dan image release wajib memakai Node `24.18.0` persis.

## Rollback/recovery

Seluruh perubahan berada di folder V2 dan belum menyimpan data. Rollback cukup menghapus artifact F0-WP01 tanpa menyentuh aplikasi lama.

## Known constraint

- Verifikasi pada runtime target Node `24.18.0` diteruskan ke F0-WP02 saat CI dibuat. Ini bukan blocker untuk menutup scaffold F0-WP01.
